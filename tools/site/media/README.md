# Rendered publication media

Upload `publication-rendered-media.zip` to this directory without extracting it. The archive supplied in the conversation contains only the three requested overview images and two path-rendered posters; no original PDFs or font files. `publication_finish.py` verifies every member by SHA-256, copies display assets into the site, and adds both poster viewers automatically. Public acceptance tests report missing assets as incomplete rather than treating a successful build as complete.
