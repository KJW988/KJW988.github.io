# 세미나 슬라이드쇼 — 한국어 / 렌더링 화면만 공개

현재는 원본이 아닌 **렌더링 묶음의 전송 대기** 상태입니다. 원본 `Archive.zip`, PPTX, PDF, 폰트 ZIP을 이 저장소에 올리지 마세요.

## 설치

이 폴더에 `seminar_rendered_public.zip` 한 개를 올리면 기존 Pages 빌드가 검사 후 `/seminars/`에 설치합니다. 홈과 블로그 메뉴도 해당 빌드에서 연결됩니다. 파일이 없으면 기존 페이지와 메뉴를 변경하지 않습니다.

승인한 묶음 SHA-256:
`ef8ad225ce8018d199cd4261577c35ff9a6f314f8e8d203b8beb99ad2bb32dda`

묶음 크기: 5,995,027 bytes. HTML/CSS/JS, 글자를 경로로 만든 SVG, 썸네일, GIF에서 변환한 영상만 포함합니다. 원본 문서·발표자 노트·숨김 슬라이드·글꼴 파일은 포함하지 않습니다. `tools`는 기존 Jekyll 제외 경로이므로 ZIP은 Pages 배포 파일에 들어가지 않습니다. 단, 공개 Git 저장소에 넣은 렌더링 묶음 자체는 저장소에서 받을 수 있습니다. 화면 저장을 차단하는 DRM이 아닙니다.

## 범위

전체 10개 발표자료의 일괄 변환본이 아닙니다. BAC 1·3·9번째 장, CLIP-RT 1·7·16번째 장, VLA-Cache PDF 1–3쪽의 총 9장·16개 화면 상태입니다. 원본 슬라이드 번호와 단계 번호를 구분합니다. PPT 글꼴은 저자가 제공한 Pretendard/Freesentation의 원본 지정을 따라 렌더링했고, PDF는 페이지별 비율을 유지합니다. 세미나에는 영어 버전을 만들지 않습니다.

## 검증

`python3 tools/seminars/install.py --require`로 승인 묶음과 파일 종류를 확인합니다. 배포 성공 후 별도 워크플로가 실제 공개 주소에서 16개 화면 상태 × 3개 너비, 단계 이동, 확대, 전체 화면, 영상 재생/정지 및 원본 문서 요청 부재를 검사합니다. 설치 대기 상태에서는 공개 사이트 검사도 명시적으로 건너뜁니다.
