## 전체본 설치

전달받은 `seminars_all_10_upload.zip`을 컴퓨터에서 한 번 풀고, 안의 `seminar_complete.part01` 등 모든 분할 파일을 이 폴더에 함께 올립니다. 분할 파일 자체는 풀거나 이름을 바꾸지 않습니다. 기존 `seminar_rendered_public.zip`은 지우지 않아도 됩니다.

빌드가 `full-manifest.json`의 모든 분할 파일이 있는지 확인하고, 개별·전체 SHA-256을 검증한 뒤 렌더링 파일만 `/seminars/`에 설치합니다. 전부 도착하기 전에는 기존 발췌 뷰어를 유지합니다. 이름만 새로 만든 빈 항목이나 부분적으로 깨진 전체 목록을 배포하지 않습니다.

이 README와 설치 코드만 반영됐다는 사실은 전체 자료가 공개됐다는 뜻이 아닙니다. 실제 범위는 `python3 tools/seminars/install.py --status`에서 `full` 또는 `sample`로 구분합니다.

## 원본 비공개

원본 `Archive.zip`, PPTX, PDF, 발표자 노트, 폰트 ZIP은 올리지 마세요. 전체 묶음에도 포함되지 않습니다. HTML/CSS/JS·글자를 경로로 만든 SVG·썸네일·재생용 영상만 포함합니다. `tools` 폴더는 Jekyll 배포에서 제외됩니다. 공개 저장소에서 렌더링 묶음을 받거나 공개 화면을 캡처하는 것까지 차단하는 DRM은 아닙니다.

세미나는 한국어만 제공합니다. 기존 연구 논문 페이지의 한영 전환과 논문 링크는 변경하지 않습니다.

## 변환 범위와 알려진 차이

- 제공된 Pretendard와 Freesentation을 적용한 사본을 SVG로 렌더링했습니다. 웹폰트 파일을 배포하지 않습니다.
- 등장·퇴장·글자색 변경은 클릭 그룹별 정적인 화면 상태로 나눴습니다. 페이드·깜빡임의 연속 움직임 자체를 재현하는 것은 아닙니다.
- PDF는 각 페이지 비율을 유지합니다. 초대형 래스터 이미지는 긴 변 4096px 이내로 조정했으며 벡터 글자와 도형은 그대로 유지합니다.
- GIF 3개와 내장 영상 5개가 재생용 자산에 포함됩니다. CLIP-RT 20번째 장의 GIF는 마지막 프레임 손상으로 정상 프레임 21초만 재생하고 해당 장에 안내합니다.
- 4K 내장 영상 한 개는 1080p로 변환했고 영상은 무음입니다. 일부 영상의 컨테이너 길이와 실제 프레임 재생 길이에 소폭 차이가 있습니다.
- CLIP-RT 17번째 장에서 화면 밖으로 나가던 첫 문장은 렌더링 사본에서 30pt→27pt로 조정했습니다. 원문 내용과 원본 파일은 변경하지 않았습니다.

## 검증

- `python3 tools/seminars/install.py --require-full`: 모든 분할 파일, 체크섬, 파일 종류, 폰트·원본 링크 제외, 10개 자료·405장·583화면 확인.
- 배포 후 `verify.py`: 공개 주소에서 583화면 × 3개 너비, 마지막 장 이동, 단계 이동, 확대·전체 화면, 미디어 재생, 원본 요청 부재를 검사합니다.
- 전체본이 아직 없는 경우 기존 샘플 16화면 × 3개 너비만 검사하며 결과에 `sample`을 명시합니다.
